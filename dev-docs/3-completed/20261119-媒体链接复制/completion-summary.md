# 媒体链接复制交付记录

分镜表格、卡片及预览可复制单镜头的视频链接。场次标题右侧可复制本场全部视频链接，每行一个，顺序与当前镜头一致。生图和生视频的结果卡片与预览复制原图或原视频。

对象存储托管媒体点击时按权限读取原媒体，经认证解密后流式写入私有交付对象，返回有效期 72 小时的预签名 GET 地址。本地托管媒体也签发 72 小时访问凭据。默认使用融光当前的默认对象存储配置。需要指定独立目标时，给后端传入 `APP_MEDIA_DELIVERY_STORAGE_CONFIG_ID`，填入已启用的对象存储配置 ID。TOS 每个交付对象写入时单独登记 4 天的保留期，清理只作用于该副本。 [TOS 对象过期说明](https://docs.volcengine.com/docs/torch-object-storage/expiringobjectsvia-api-s?lang=zh)

当前工作区实现完成。14 项后端定向测试通过，含 72 小时签名、本地凭据到期时间和交付对象生命周期冲突。此前 31 项前端定向测试、TypeScript 和改动文件 ESLint 通过。Chromium 以模拟存储接口验证了复制、拖拽后的顺序、签名失败时保留剪贴板和无登录会话访问。真实 `tos-01` 桶权限与生产部署尚未验收。
