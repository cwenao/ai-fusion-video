# 对象存储交付边界

复制对象存储托管媒体时，交付副本使用对象存储的服务端加密。TOS 上传时为单个对象设置 4 天过期，之后由 TOS 按对象过期时间清理。S3 交付目标须启用 `afv-media-delivery/` 前缀的至少 4 天过期规则。签发前检查交付对象可能命中的提前归档规则，S3 也检查更早的过期规则，避免预签名链接有效期间对象无法读取。

交付对象显式使用私有 ACL。TOS 允许桶 ACL 的公开读取授权，校验桶写入与 ACL 修改授权仅授予明确账号，并要求桶策略为空、未开启版本控制和跨地域复制。业务凭据需拥有读取这些设置、读取生命周期规则与对象读写删除的权限。S3 校验全部阻止公共访问选项、桶策略与版本控制。签名链接在 72 小时内由持有链接者访问，融光在签发前复核当前媒体权限和版本。 [TOS 对象 ACL 说明](https://docs.volcengine.com/docs/TorchObjectStorage/ConfiguringobjectACLs?lang=zh)

72 小时从新链接签发时起算。已签发的短时链接需要重新复制。历史外部直链由原存储方控制有效期。对象存储密钥撤销或对象被主动删除会导致链接失效，本地链接在访问时复核权限和资源版本。

生产 `tos-01` 使用 TOS 默认域名。无登录浏览器打开实测链接时直接下载。浏览器内在线预览使用桶绑定的 HTTPS 自定义域名。生产验收核对了签名参数和当前访问行为，链接时效由对象存储按签发时间执行。 [TOS 浏览器预览说明](https://docs.volcengine.com/docs/TorchObjectStorage/Howtopreviewobjectsinabrowser?lang=zh)
