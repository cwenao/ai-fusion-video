# 媒体链接复制

分镜表格和卡片在每个已有视频的镜头上提供复制按钮。场次标题右侧复制本场次全部视频，每行一个链接，沿用工作区当前镜头顺序。每个镜头采用当前显示的视频，历史视频字段在未生成新版视频时仍可使用。

生图和生视频的创作记录及结果预览复制原图或原视频。已有的 HTTP(S) 对象存储链接保留签名，本地资源路径转换成完整浏览器地址。本地托管媒体按需签发融光访问链接，对象存储托管媒体按需发布到当前默认私有对象存储的 `afv-media-delivery/` 前缀，返回对象存储预签名 GET 地址。复制入口签发的托管媒体链接从签发时起有效 72 小时，用于任务重试。

验证重点包括实际剪贴板、拖拽后顺序、签名参数、拒绝未授权访问、交付失败清理、源媒体版本变更，以及复制链接在新浏览器会话中的访问。
