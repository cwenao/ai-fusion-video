# 生成素材 AI 审查交付记录

分镜的单镜和批量视频、首尾帧、场次子资产生图，以及工具生图和生视频，都可以在提交时勾选「生成后 AI 审查」。默认关闭，只对本次任务生效。「只生提示词」不提交审查。审查模型来自已启用且支持对应媒体 Base64 输入的对话模型。

每份生成成功的素材各有一条审查记录。工具任务使用实际提交的提示词，项目任务同时固定对应镜头、场次或资产设定。后台异步读取托管素材，给出「符合要求」「需要修改」「无法确认」和依据、修改建议、限制。审查等待、超时和失败独立显示，生成结果可直接使用。创作记录、镜头详情和场次资产列表可查看各自的结果。

已核对上游正式发布边界为 `v1.3.0`，新增开发版迁移 `V1.1.4.0.1`。本地 MySQL 8.4 完成迁移并通过 Flyway 校验。后端定向测试覆盖未勾选、幂等、分镜选择范围、跨账号权限、逐份审查、无效结论与完整视频传输。FFmpeg 实测 5 秒大视频转码后保留原时长和音轨。前端生成定向测试、TypeScript 检查、改动文件 ESLint 检查通过；在本地浏览器验证了选项、结果详情及窄屏深色模式下的键盘焦点。

审查不会二次发送原始参考图、参考视频或参考音频，相关条件无法判断时会在结果中说明。未部署；使用真实项目素材和审查模型进行的人工验收待完成。
