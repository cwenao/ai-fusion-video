# 资产多表现同步完成记录

同一主资产下可维护多种表现。子资产新增可选「时间线」和「表现状态」，沿用独立 ID、外观、提示词和媒体；项目内 AI 起草外观及生图提示词时把标签一并带入。从资产库打开项目资产时，进入同一资产页查看和编辑。

MCP 新建主资产支持按序原子创建 1 至 50 个子资产，返回每项 ID 和版本；不传数组的旧调用仍创建一个初始项。已有主资产通过子资产列表发现各表现，通过原有工具逐项追加或更新；保留项目权限、版本校验及请求幂等。无数据库迁移。

本地定向验证通过：后端 14 项（包括隔离 MySQL 上的多项创建和重试），前端 11 项及 TypeScript 校验。真实 MCP 创建两种表现，Chrome 在项目资产页修改并清空其中一项的状态，再新增第三种表现；MCP 列表读回相同 ID 和变更。覆盖分页、旧请求、只读拒写、跨项目隔离、旧版本冲突、非法输入、幂等重试，以及桌面浅色和窄屏深色下的表单焦点、禁用和错误反馈。已验证资产库跳转到对应的项目资产。
