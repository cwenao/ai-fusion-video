# 同一资产的多种表现

主资产保存同一个角色、场景或道具的身份和共用设定。多种表现沿用已有的子资产，每项保持独立 ID、媒体、外观描写和生图提示词；时间线、表现状态是可省略的文本标签，可同时填写，不参与排序或合并。

项目资产页可编辑和查看标签，跨项目资产库通过所属项目访问详情。项目内 AI 起草外观和生图提示词时读取当前子资产的标签。分镜继续引用精确的子资产 ID。

项目 MCP 新建主资产时支持按顺序提交 1 至 50 个子资产，写入同一命令，首项延续初始项约定；不提交数组时保留原有创建行为。已有主资产可分页读取、逐项追加或更新；子资产修改仍校验子资产和父资产版本，媒体走既有绑定工具。

以真实本地 MCP、网页读写和独立子资产 ID 为验收依据，并检查旧请求、非法输入、版本冲突和幂等重试。
