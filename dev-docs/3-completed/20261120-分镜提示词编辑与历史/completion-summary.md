# 分镜提示词编辑与历史

镜头卡片新增“编辑提示词”，默认打开视频提示词。详情里的三类提示词也进入同一个编辑框。桌面左侧是接近全高的文本区，右侧提供 Agent 多轮聊天。窄屏纵向排布，提示词、对话记录及输入区均可以滚动访问。

视频、首帧和尾帧分别保留编辑草稿、对话和最近三个有内容的历史版本。历史来自现有业务修订，随已保存的镜头版本刷新。点击历史可只读预览，载入旧版或应用 Agent 建议会先更新草稿。保存只提交当前提示词字段和镜头版本。并发更新时可以核对最新版，选择载入或保留自己的草稿后重试。

隔离 MySQL 与 Redis 验证了历史上限、顺序、字段隔离、原文及权限，分镜后端共通过七项定向测试。前端通过七项分镜回归、类型与改动文件静态检查。Playwright 在桌面亮色和窄屏暗色验证了长文本、历史切换、两轮 Agent 对话、采纳、保存、版本冲突、丢弃确认及表单的焦点和禁用状态。

候选前后端镜像通过生产构建。使用与生产相同的默认文本模型 `deepseek-flash`，在隔离数据库中从镜头卡片完成两轮真实对话。第二轮引用第一轮约定的信息，后端记录两次模型调用均已完成。采纳建议后确认已保存内容仍为原稿，保存后刷新读回新稿，并逐个切换最近三个历史版本。人工验收待完成。
