# 分镜与资产 AI 编辑

- 单镜头及场次批量首尾帧生成使用图片模型的比例、分辨率和默认配置，后端按已提交的选择执行。
- 卡片视图右栏展示所选镜头的视频、首帧及尾帧提示词，支持手动修改、AI 多轮起草和版本化保存。
- 子资产新建与编辑支持依据资产类型、名称、主资产描述及现有草稿生成外观描写，经用户采用后沿用原保存流程。
