# 交付记录

整部剧本与分集可粘贴 Markdown 或导入 UTF-8 的 `.md`、`.markdown` 文件。导入后仍可编辑源码并切换预览。浏览器实测标题、列表、引用、加粗和表格可预览；保存保留原文中的标记、缩进及换行。纯文本仍可编辑、保存和按行阅读。

「AI 解析该集」预览已保存的原文，提交确认的分集版本，由解析助手读取对应原文。版本变化会更新预览并取消旧确认。整部及分集解析提示说明如何从 Markdown 提取分集、场次、动作和对白。

MCP 的 `rawContent` 和 `originalText` 指向同一份剧本原文；`synopsis` 是剧情概述。定向测试覆盖原文逐字回读、版本冲突、字段别名、同传冲突和按需省略原文。浏览器使用本地测试接口验证了两个入口的完整操作及解析任务提交。真实模型解析质量和正式环境尚未验收，本次未部署。
