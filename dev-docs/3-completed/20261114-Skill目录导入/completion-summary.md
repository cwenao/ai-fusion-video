# 完成摘要

目录上传每个文件分别携带文件内容和相对路径。25 个文件预检使用 50 个分段，正式导入附带的选择参数是第 51 个分段，超过了 Tomcat 默认上限。此前上传异常经通用处理器返回 HTTP 500。

Tomcat 现在允许 2001 个分段，覆盖现有最多 1000 个文件的目录导入协议。上传分段过多或体积超限时返回 HTTP 413，并给出相应提示。

在真实 Tomcat 和隔离 MySQL、Redis 中验证 25 个文件预检、正式导入和列表回读。另验证 1000 个文件可预检、1001 个文件返回明确的超限提示。HTTP 集成、控制器和导入服务共 9 项定向测试通过。正式环境仍待部署和复验。
