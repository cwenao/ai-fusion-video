# 分镜视频断线与排队完成记录

单镜头与批量入口共用同一提交和刷新逻辑。已取得运行 ID 的任务在断线后按上次事件位置重连，并通过后台状态查询收尾。重连事件和状态查询共享完成通知，同一运行只触发一次完成回调。页面通过既有资源同步读取入库并写回的镜头。

生成任务首次领到并发名额时开始两小时的执行计时。此前的队列等待不消耗这个窗口，轮询和接管沿用领取时的截止时间。

39 项前端定向测试及 TypeScript 检查通过。MySQL 队列用例验证过期待领取任务恢复和接管后的截止时间。三项后端端到端场景覆盖单镜头回填、并发编辑的版本冲突保护、双镜头在断线后依次取得名额并各自完成写回。供应商由本地 HTTP 桩模拟。生产部署、历史任务修复和人工验收待确认。
