# 分镜视频提示词与画面内容修复

单镜头视频弹窗预览已保存的视频提示词，保留换行。项目分镜生成工具通过同一次镜头版本校验取得已保存的提示词，在视频任务构建时使用原文。批量任务按各镜头分别取值。空提示词镜头继续由生成流程编写提示词。

镜头详情提供画面内容编辑和保存，桌面侧栏与窄屏抽屉均可使用。更新请求只提交画面内容及镜头版本。版本冲突时显示最新内容并保留本地草稿，由用户确认后按新版本重试。

隔离集成测试确认供应商收到已保存提示词，覆盖单镜头回填、生成期间并发修改画面内容、同批含有提示词与无提示词镜头且断线等待。浏览器验证卡片和表格入口、桌面保存后刷新、窄屏空镜头编辑、表单焦点与保存禁用态、版本冲突及取消。前端类型检查及分镜刷新与断线定向测试通过。

本次修复已在本地完成。生产部署及真实供应商验收待完成。
