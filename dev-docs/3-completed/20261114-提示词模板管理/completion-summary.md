# 完成摘要

管理员可通过「系统设置 → 提示词模板」新建、编辑和删除共享 Markdown 模板。所有登录用户可以在资产管理的单项和批量生成入口中，选择适用于角色、场景、道具的自定义模板或通用模板。现有内置模板仍可选用。

选中的 Markdown 模板正文和项目类型、画风、比例、主资产定义、子资产外观一起交给提示词智能体。批量默认跳过已有提示词的子资产。用户仍可修改并保存生成结果。删除模板后，资产中已经保存的提示词会保留。

隔离 MySQL 和 Redis 集成测试验证了管理员写入、普通用户只读、模板增删改、缓存刷新和 Markdown 回读。浏览器模拟验收覆盖桌面和窄屏表单、单项和混合类型批量生成、按类别筛选和删除后的选项更新。TypeScript 与改动文件 ESLint 检查通过。正式环境部署和真实模型验收待进行。
