# 项目 MCP 批量操作完成记录

项目 MCP 新增 13 个工具。剧本、分镜和资产各增加批量读取、新增、修改。提示词支持批量读取与设置，媒体支持批量读取原件元数据和绑定槽位。保留剧本场次、分镜场景或镜头、主资产及子资产的三个批量删除工具。

每批在同一项目内处理 1 至 20 个同类对象，按输入顺序返回结果。批量写入复用单条的业务校验和权限边界，整批在一个事务内提交，记录一份命令回执。每个受影响资源返回最终版本。同一请求标识原样重试返回原回执，改动内容后重用会报冲突。

Java 21 定向测试共 24 项通过，无失败或跳过。通过隔离应用的 `/api/mcp` 完成协议握手，发现 39 个工具并调用验证 16 个批量工具。已核对读取顺序、剧本原文开关、共享父版本、请求重放、只读凭证、跨项目隔离、版本冲突、媒体类型不匹配时回滚，以及删除资产项后仍可读取媒体原件。

本地实现与隔离验收完成。正式环境尚未部署或验收。
