# 项目 MCP 批量操作

为剧本、分镜、资产补齐按 ID 批量读取、批量新增和批量修改，沿用已发布的三个批量删除工具。提示词增加批量读写，媒体增加批量元数据读取和槽位绑定。

每批接收同一项目内 1 至 20 个同类对象。批量新增的直属子对象共享父对象和起始版本，批量修改的每个对象携带自身版本，更新子资产时另携带其主资产的起始版本。批量写入使用单条业务命令的校验和处理器，在一个事务内提交并登记统一回执。读写按提交顺序返回结果，受影响资源以最终版本返回。

验收覆盖 MCP 工具发现、请求参数、项目隔离、只读权限、幂等重放、失败回滚和共享父资源版本。媒体验收包括可下载原件的读取、类型检查、绑定和删除业务对象后保留原件。
