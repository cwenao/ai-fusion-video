# 对象存储媒体直读完成记录

资产原图、预览图和分镜视频共用托管媒体访问流程。TOS 和 S3 兼容对象的媒体字节由浏览器使用短时签名地址发起 Range GET，Service Worker 认证解密后提供给图片和视频元素。融光负责媒体权限校验和签发授权。磁盘托管媒体继续使用短时应用访问凭据。

分镜视频在点击下载时准备私有交付副本并签发 5 分钟的对象存储链接，保留原始文件名。复制媒体链接的 72 小时有效期沿用既有契约。

24 项后端定向测试、18 项前端定向测试、TypeScript 检查和变更文件 ESLint 检查通过。集成测试使用本机缓存的 MinIO 镜像，真实签名 Range GET 返回 HTTP 206。隔离 Chromium 解码了原图、缩略图和视频，完成拖动及从存储端点下载原文件。下载字节与原件一致，应用媒体转发请求为 0。生产尚未发布和验收。
