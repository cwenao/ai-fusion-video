# 资产参考生成入口

## 目标
- 生图、生视频的简洁及高级模式提供“从资产库选择”，支持多选、原始媒体预览、顺序调整。
- 项目资产详情提供“用于生图 / 用于生视频”，跳转后自动加入参考栏。
- 复用原始媒体引用，不下载重传，不以视频封面替代视频。

## 实施（全部完成）
1. 集中解析服务端登记的原件字段和零起始版本；跳转仅携带资产/子资产/项目/字段标识与版本，接收时重新读取并校验。
2. 共享选择器按项目浏览并预览；原子校验模型类型、总量、去重及顺序，不静默截断；图、视频、音频独立编号。
3. 生成页保存项目上下文，实际请求与待确认重试请求均保留项目；手动切换模型清空参考前须明确确认。
4. 完成回归、生产构建、部署及桌面/窄屏/明暗主题浏览器验收；清理专用验收数据。

## 边界
不改变资产存储、模型配置、ComfyUI 工作流、数据库结构或媒体卷。缺失、越权、版本过期、不支持的媒体须显式报错。
