# 资产参考生成入口交付总结

## 最终范围
- 生图与生视频的简洁、高级模式均可从资产库选择。支持项目/非项目来源、搜索、多选、原图/完整视频/音频预览、有序选择及参考栏再次排序。
- 已保存子资产详情提供用于生图/用于生视频；按真实类型带入。视频/音频不冒充图片，草稿或正在保存/上传时禁止跳转。
- 跳转只包含业务标识、版本和原件字段；接收时重新授权读取并校验。空参考栏自动选择兼容模型；已有参考不会被自动切换模型丢弃。
- 实际生成及重试请求保留项目和原始 media://；服务端既有权限、媒体版本冻结和执行校验保持不变。
