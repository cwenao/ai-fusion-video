# MCP 批量删除完成记录

项目 MCP 新增三个工具，可按每项版本批量删除剧本场次、分镜场景或镜头、主资产或同一主资产下的子资产。每批接受 1 至 20 个明确 ID。分镜场景和主资产沿用既有级联软删除规则，媒体原件保留。

整批使用一个事务和一个幂等回执。重复、越权、版本冲突和异常均回滚。共享父对象在回执和事件中提供最终版本，保留命令审计和变更前记录。无数据库迁移。

后端定向测试 16 项通过。隔离 MySQL、Redis 与应用完成真实 MCP HTTP 握手和工具发现，验证五种目标类型、级联删除、未选对象保留、旧版本回滚、冲突详情、只读与跨项目拒绝、重复目标及幂等重试。生产部署和正式环境验收尚未执行。
