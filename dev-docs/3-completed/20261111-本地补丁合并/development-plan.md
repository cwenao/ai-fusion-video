# 本地补丁合并计划

## 范围
将无 Git 元数据的 afv-qwen-patch 工作副本合入指定本地仓库的 main（起点 308cd8f），包含 Qwen/ComfyUI 选择器和可选多媒体输入、MiniMaxH3 工作流契约、资产库参考入口及三组交付文档。

## 实施
1. 检查目标未提交状态，按实际差异确定新增及修改文件，不删除目标独有文件。
2. 同步前后端互相依赖的实现、回归测试和文档，保留目标部署配置与依赖锁文件。
3. 完成前端构建、独立类型检查、变更文件 lint、现有脚本及新增契约测试；使用隔离 Java21 环境执行后端定向回归。
4. 核对最终 diff 后创建本地提交，不推送、不部署、不操作线上数据。

## 不在范围
不复制构建产物、node_modules、临时备份或验收附件；不复制服务器专用 Compose/Dockerfile。不导入或发布任何数据库中的模型/工作流记录。
