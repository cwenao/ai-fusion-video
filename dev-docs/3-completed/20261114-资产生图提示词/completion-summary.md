# 完成摘要

子资产分别保存外观描写和生图提示词。「AI 写提示词」可选择角色设定图、角色三视图、场景概念图、道具设定图或通用资产图模板。点击「一键生成」后，AI 按选中模板组织 Markdown，结合项目类型、画风、画面比例、资产定义及外观描写。项目比例用于构图，实际出图参数沿用生图时所选的模型和比例。用户可采用候选稿、编辑 Markdown、预览或清空后保存。每份提示词最多 5000 字符，复用现有子资产属性存储。

资产生图执行器只用已保存的提示词。服务端在目标权限及版本校验后读取原文，保留 Markdown 和空白格式，独立处理模型及参考图。外观描写和历史出图记录继续用于资产定义与追溯。缺少提示词时不会提交生成。
