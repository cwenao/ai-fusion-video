# 完成摘要

项目资产管理的「批量生成提示词」支持逐项勾选和全选缺少提示词，已有提示词需要手动勾选才会生成新草稿。角色、场景、道具可分别选用本类型模板或通用模板。每项请求沿用当前项目类型、画风、比例、主资产定义和该子资产外观。

使用现有提示词智能体按顺序生成独立 Markdown 草稿，失败项可单独重试。逐项保存时仅更新生图提示词，并校验子资产和父资产版本。窗口内可提交本批已保存的条目进行批量生图。

浏览器模拟验收覆盖跨类型模板、已有提示词跳过、单项失败重试、同一主资产连续保存、并发修改冲突、窄屏校验和生图对象范围。TypeScript、ESLint 和 19 项前端生成测试通过。正式环境及真实模型验收待部署后进行。
