- 6 张参考图：第 1 张必需，第 2–6 张可选；参考视频、参考音频各 0–2 项。

## 完整输入与输出映射

| 平台字段 | 工作流位置 | 约束/行为 |
|---|---|---|
| prompt | 101.prompt | 正向提示词；参考标签使用 Picture/Video/Audio 的序号 |
| seed | 65.noise_seed | 随机种子 |
| duration | 55.value → 57 帧数表达式 | 秒，可在试运行中填小数；模型按 24fps 和帧组取整 |
| aspectRatio | 52.aspect_ratio | 8 种比例；平台短值转换为节点的真实枚举标签 |
| megapixels | 52.megapixels | 首采目标百万像素；宽高仍由选择器节点输出，不覆盖连线 |
| resolutionMultiple | 52.multiple | 尺寸对齐倍数，8–128，步长 4；当前保存值 32 |
| upscaleMegapixels | 62.value | 二采目标百万像素；当前保存值 0.8 |
| referenceImages[0…5] | 1.ref_images.ref_image_0…5 → 加载器 18…23.image | 首项必需，其余显式 optional；严格保序 |
| referenceVideos[0…1] | 1.ref_videos.ref_video_0…1 → 加载器 30…31.video | 可选，以 24fps 帧序列作参考；不自动把视频内音轨冒充独立音频参考 |
| referenceAudios[0…1] | 1.ref_audios.ref_audio_0…1 → 加载器 32…33.audio | 可选独立音频参考 |
| 主视频结果 | 98，video / primary | 二采、H.264 MP4、含模型生成音轨，持久保存 |
| 一采预览 | 87 | 只作中间预览，不作为主结果返回 |

没有给原图不存在的负向提示词、动态帧率或批量数量伪造绑定。当前固定 24fps、每次 1 个结果；不提供参考音频时仍能生成带音轨视频。普通生成的封面及首尾帧由平台媒体入库流程提取。

### 参数在哪里设置

- 普通生成：画面比例、首采 MP 档位、时长、种子、参考素材。
- AI 配置 → 工作流 → 验证发布：上表全部业务输入，包括对齐倍数与二采 MP，均可逐项设置和试运行。
- 修改长期默认值：复制已发布版本，再修改节点 52 的三个选择器参数、节点 62 的二采像素值，校验/试运行成功后发布。不要把 width/height 绑定到主节点以绕开选择器。
- 普通生成默认首采 0.5MP、时长 5 秒，档位 0.3/0.5/0.8/1MP；工作流时长原保存值 12.5 秒，试运行留空会继承保存值。建议首次试运行明确填写 5 秒。
- MP 是目标面积而非精确宽高；帧组对齐使 5 秒请求实际约 5.167 秒。

## 导入副本的必要修正

1. 原实验性 SageAttention 优化节点在服务器依赖下直接报版本不满足。只在导入副本删除该优化节点，LoRA 直接连接原 UNET，保留低显存注意力与两段采样；没有安装、升级或修改 ComfyUI 全局依赖。
2. 原音频 VAE 加载器误指向视频 VAE，导致音频解码维度错误。节点 8 改用服务器现有的音频 VAE，参考音频及输出音频均真实运行通过。
3. 第二个参考视频统一 24fps；最终视频节点启用持久保存。
4. 静态文件默认值仅用于在线加载器选项校验。实际提交必须提供首图；其余素材由显式输入替换或按可选规则删除。

用户原始 JSON 文件未修改。

## 运行边界

当前模型并发为 1。满槽验证使用小型合成素材，不保证任意大图、长片段或高 MP 在 24GB GPU 上都能运行；图片/视频/音频分别限制 20/200/50 MiB，参考视频/音频长度 2–15 秒。分辨率越高、素材越多、生成越长，显存和耗时越高。
