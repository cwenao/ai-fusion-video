- 这是部署侧补丁，未来升级官方 ai-fusion-video 后须重新合入并验证，不能直接切换 latest 覆盖。
- 选择器像素档位控制首采，二采目标像素由独立 upscaleMegapixels 控制。普通生成界面提供比例与首采档位；对齐倍数、二采目标可在 AI 配置工作流及试运行中设置，不假称普通生成表单已有这两个控件。
