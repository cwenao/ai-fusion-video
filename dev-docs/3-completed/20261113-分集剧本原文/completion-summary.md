# 分集剧本原文交付记录

「剧情概述」下方显示原文，点击「编辑」或「填写」打开分集编辑页。一键改写使用默认对话模型润色整集，可基于当前改写稿继续提交文字要求。点击「采用改写」后可手动编辑，点击「保存」提交原文。版本冲突时保留草稿，并显示最新保存内容供核对。

「AI 解析该集」直接展示已保存的原文和已有场次数。原文为空时提供填写入口。分集版本变化时刷新预览并重新确认。解析助手读取原文字段，按版本提交场次和对白。

网页与解析工具使用 `rawContent` 读取已保存的分集原文。MCP 早期在 `rawContent` 返回原文，后续调整用它返回概述并新增 `originalText`。现行 MCP 将两者映射为同一个原文字段，剧情概述由 `synopsis` 单独读写。数据库沿用同一列 `raw_content`。

前端 TypeScript 与改动文件 ESLint 检查通过。后端定向测试通过，覆盖原文查询、版本冲突、空原文、改写工具隔离及流式正文的换行和缩进。桌面与窄屏浏览器使用本地测试接口验证了连续改写、保存、解析回读、失败重试和长弹窗键盘操作。真实模型联调与正式验收待进行。

字段统一后，29 项后端定向测试通过，覆盖 MCP 原文分页与省略、两个原文写入名及冲突、概述独立更新、AI 读取已保存原文和版本校验。使用本地模拟接口验证了网页分别显示概述和原文、编辑只保存原文、解析预览读取最新已保存的原文，以及空原文时提供填写入口。前端 TypeScript 与修改范围 ESLint 检查通过。
